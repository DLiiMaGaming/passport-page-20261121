A program that draws, fully programmatically, one open passport spread for
**Veldoria** — an island nation that does not exist. The data page carries a
drawn portrait, trilingual labels and a machine-readable zone; the visas page
carries arrival and departure stamps from the neighbouring states of Tarnovia
and Ostara, a harbour-fee stamp, and a visa condition (register with the
Harbourmaster within 48 hours) that says what kind of place Veldoria is.

## Run

```sh
python3 main.py   # writes /output/entry.png (1024x720 PNG)
```

Deterministic: two runs produce byte-identical PNGs. Python 3.13, Pillow only.
